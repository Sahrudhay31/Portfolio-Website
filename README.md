# Portfolio Website

This repository contains the source code for my personal portfolio website. The site is designed to present my projects, technical skills, and background in a clear and accessible format.

## Overview

The portfolio serves as a central place to showcase my work and provide information about my experience in web development. It is built with a focus on simplicity, responsiveness, and performance.

## Features

- Responsive layout compatible with desktop and mobile devices  
- Structured sections for projects, skills, and personal information  
- Clean and minimal user interface  
- Lightweight and fast-loading design  

## Technologies Used

- HTML5  
- CSS3  
- JavaScript
